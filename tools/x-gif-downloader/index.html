X GIF Downloader — Project Note

X GIF Downloader is a small browser tool for public X and Twitter posts. Paste a post URL, preview its animation, then export a real .gif file or keep the original MP4.

The format choice matters because X normally serves so-called GIF posts as looping MP4 video. Renaming that file does not turn it into a GIF; an actual conversion is required.

Open X GIF Downloader

Useful when

  • a CMS or chat app requires a real GIF;
  • you want the smaller, higher-quality original MP4;
  • you need to preview a public post before choosing a format.
